# 后续规划（Roadmap）

本项目当前处于 **v0.1.0 原型阶段**：前端流程完整、数据存放在本地缓存。
以下是计划中的迭代方向，欢迎认领。

---

## v0.2.0 · 流程补全（纯前端可完成）

- [ ] 新建 `pages/audit-pending` 审核等待页，修复 `app.js` 中跳转到不存在页面的问题
- [ ] 接单成功后自动创建会话，打通「接单 → 聊天」链路
- [ ] 订单超时自动取消（`expireTime` 生效，可在 `onShow` 中做惰性检查）
- [ ] 聊天对方昵称解析：维护 `verifiedUsers` 或从订单的 `creatorNickname / takerNickname` 回填
- [ ] 完成订单后更新 `credit` / `completedOrders` / `publishedOrders` 统计
- [ ] 移除 `pages/orders/orders.js` 中的调试 `console.log`

## v0.3.0 · 接入后端

- [ ] 设计数据库表结构（参考 `docs/数据模型.md`）
- [ ] 用户服务：微信登录 `code2session`、JWT 签发与校验
- [ ] 订单服务：发布 / 接单 / 取消 / 完成 / 列表分页
- [ ] 消息服务：WebSocket 实时推送 + 历史消息拉取
- [ ] 对象存储：学生证与人脸照片上传（目前 base64 生成后被丢弃）
- [ ] 统一请求封装：`app.js` 中 `https://your-api.com` 替换为真实域名并抽出 `utils/request.js`

## v0.4.0 · 体验增强

- [ ] 真实身份认证：学生证 OCR + 人脸比对
- [ ] 评价体系：双方互评，与信用分联动
- [ ] 在线支付 / 赏金托管
- [ ] 订阅消息通知（接单、完成、新消息）
- [ ] 地图选点接入 `wx.chooseLocation`，替代手写地点
- [ ] 未读消息全局红点
- [ ] 骨架屏与下拉刷新、上拉加载

## v0.5.0 · 工程化

- [ ] TypeScript 改造
- [ ] 抽离公共组件（`components/`）与工具函数（`utils/`）
- [ ] 引入 ESLint + Prettier 统一代码风格
- [ ] 单元测试与 CI 检查
- [ ] 分包加载与性能优化

---

## 非目标（Out of Scope）

- 不做跨校区的社会化运营
- 不做金融结算，赏金支付将交由第三方支付能力完成
- 不存储原始人脸照片，仅保留比对结果与脱敏标识
