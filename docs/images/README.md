# 项目截图目录

请把小程序各页面的截图放到本目录下，文件名与下表保持一致，README 会自动引用。

## 推荐命名

| 文件名 | 对应页面 | 建议内容 |
| --- | --- | --- |
| `home.png` | `pages/home/home` | 首页概览（待接单数量 + 最近订单） |
| `place.png` | `pages/place/place` | 发布需求表单 |
| `receive.png` | `pages/receive/receive` | 接单大厅列表 |
| `orders.png` | `pages/orders/orders` | 订单中心（我发布的 / 我接的） |
| `login.png` | `pages/login/login` | 身份认证页 |
| `chatList.png` | `pages/chatList/chatList` | 会话列表 |
| `chat.png` | `pages/chat/chat` | 聊天页 |
| `profile.png` | `pages/profile/profile` | 个人中心 |

## 获取截图的方式

1. 微信开发者工具模拟器 → 右上角「...」→ **生成预览图 / 截图**；
2. 或直接系统截图，建议统一为 iPhone 6/7/8 尺寸（750×1334）或 2 倍图宽度 750px。

## 注意

- 截图前请先**清空演示数据中的真实个人信息**（手机号、学号、真实姓名）。
- 单张图片建议控制在 500KB 以内，避免 README 加载缓慢。
